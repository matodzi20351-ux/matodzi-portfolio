# Matodzi Portfolio — Version 4

A real React + Vite portfolio source project. Light editorial design, canvas particles, animated hero, project filters, certificate preview modal, responsive layouts, reduced-motion support, and optimized WebP images.

## Run locally

1. Install Node.js 20+.
2. Open this folder in VS Code.
3. In the terminal run `npm install` then `npm run dev`.
4. Open the local URL Vite displays.
5. For deployment run `npm run build` and upload the `dist` folder to Netlify, or connect this project to GitHub and deploy with build command `npm run build`, publish directory `dist`.

## Edit content

Edit `src/main.jsx`: `projects`, `certs`, and `skills` arrays. Edit styles in `src/style.css`. Images are in `public/assets`.

## Notes

- The four Netlify projects retain temporary names until you supply their actual titles.
- SheShield points to the link you supplied.
- GitHub currently points to the account from your previous project messages; change if needed.
- Contact email is based on the email you previously shared; edit if you prefer a different public email.
- This portfolio contains animated graphics but no actual video footage. Add your own licensed video to `public/assets` and a `<video>` element if you want background video.
